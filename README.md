# 魔术接单 · 个人随身话术库

适合 iPhone 添加到主屏幕使用的网页 App。

正式网址：https://killng.github.io/magician-playbook/

- 8 个场景、52 条接单话术，支持全文搜索和复制。
- 常用话术收藏，保存在本机。
- 三档套餐及差旅、加项、优惠、预付款计算，报价草稿自动保存。
- 添加到主屏幕后可离线使用，首次从桌面图标打开时需联网完成缓存。
- 首页「报价计算器」和底部「报价计算」均可进入报价页面。

## 发布到 GitHub Pages

这是纯静态项目，无需安装依赖或构建。

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 /(root)，保存即可。
网页的实际访问地址以 Pages 设置页显示为准。项目目录路径已兼容。
GitHub Pages 不使用 24 小时临时链接机制，但持续可用仍取决于账号、仓库和平台服务状态。

## iPhone 安装

1. 在 Safari 打开 Pages 网址。
2. 点分享按钮 → 添加到主屏幕。
3. 从桌面图标联网打开一次，等待首页显示「离线可用」。

不需要苹果开发者账号、签名或 App Store 上架。

## 数据与访问范围

这是公开的静态网页，没有登录限制。拥有网址的人可以看到页面和内置话术。
收藏及报价草稿保存在当前设备的浏览器存储里，应用不会把它们上传。
Safari 与桌面 App 的存储可能分开，建议日常从桌面图标使用。
清理网站数据、换手机或卸载后，本机内容可能丢失；系统清理缓存后，需要联网重新加载。

## 更新

修改页面文件后，同步调整 sw.js 中的缓存版本，再推送到 GitHub。
